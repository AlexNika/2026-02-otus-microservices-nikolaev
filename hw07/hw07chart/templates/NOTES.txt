HW07 microservices installed (release: {{ .Release.Name }}, namespace: {{ .Release.Namespace }}).

1. Get the minikube IP and map the host:
     minikube ip
   Add to C:\Windows\System32\drivers\etc\hosts (as Administrator):
     <minikube-ip> {{ .Values.ingress.host }}
   If the ingress is not reachable, run in a separate elevated PowerShell window:
     minikube tunnel

2. Application endpoints (base URL: http://{{ .Values.ingress.host }}):
     GET  http://{{ .Values.ingress.host }}/health/user
     GET  http://{{ .Values.ingress.host }}/health/billing
     GET  http://{{ .Values.ingress.host }}/health/order
     GET  http://{{ .Values.ingress.host }}/health/notification
     POST http://{{ .Values.ingress.host }}/api/v1/auth/register
     GET  http://{{ .Values.ingress.host }}/api/v1/account/user/{userId}
     POST http://{{ .Values.ingress.host }}/api/v1/account/{userId}/deposit
     POST http://{{ .Values.ingress.host }}/api/v1/order
     GET  http://{{ .Values.ingress.host }}/api/v1/notification?userId={userId}

3. Check pod status:
     kubectl get pods
